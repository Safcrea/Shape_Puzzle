# Shape Puzzle

A colorful **2D shape-assembly puzzle game** where players drag and rotate individual pieces to rebuild complete toys, vehicles, animals, buildings, and other playful objects.

The game is designed for mobile devices with simple controls, short levels, clear visual feedback, and gradually increasing difficulty.

## Game Overview

In each level, the player is shown a completed reference image and a collection of puzzle pieces. The objective is to place every piece in the correct position and orientation using as few moves as possible.


<img width="941" height="1672" alt="PuzzleToyShape" src="https://github.com/user-attachments/assets/fbfd3b54-6063-46ae-8c16-0e8f9844dd28" />

### Core Gameplay Loop

1. Study the completed reference shape.
2. Drag a loose piece toward the puzzle board.
3. Rotate the piece until it matches the target slot.
4. Place the piece in the correct position.
5. Complete the full object to unlock the next level.
